# kaBAGA Academy — How to Create a Course

**For:** Instructors and ETD / Admin staff  
**System:** kaBAGA Academy LMS

This guide follows the **actual process** in the system: create a draft → set up the course workspace → add modules and assessments → publish.

---

## Overview (Recommended Order)

| Step | What you do | Where |
|------|-------------|--------|
| 1 | Create a **draft course** (title, modality, categories) | Manage Courses → Create Course |
| 2 | Finish **Overview** details | Course workspace → Overview |
| 3 | Add **Modules** (lessons) | Course workspace → Modules |
| 4 | Add **Pre / Post assessments** and **video checkpoints** | From each module’s badges |
| 5 | Set **Access** (optional) | Course workspace → Access |
| 6 | Assign **Instructors** | Course workspace → Instructors |
| 7 | Set **Certificates** (optional) | Course workspace → Certificates |
| 8 | Add **Batches** if needed (optional) | Course workspace → Batches |
| 9 | **Save**, then **Publish** | Course list / course page |

**Important:** Creating a draft only saves the basics. Learners cannot take the course until you add modules and **Publish**.

---

## Step 1 — Create a Draft Course

1. Sign in as an instructor or admin.
2. Open **Manage Courses** in the left menu.
3. Click **Create Course**.
4. Fill in the **Quick create** form:
   - **Course title** (required) — e.g. *Infection Control and Prevention*
   - **Description** — short overview of the course
   - **Modality** (required) — e.g. Online, Blended, Face-to-Face
   - **Categories** — select one or more training categories
   - **Primary owner** (Admin only) — who owns / teaches the course
5. Click **Create draft course** (or the save button shown).

You are taken to the **Course Workspace**, where you finish setup.

---

## Step 2 — Overview Tab

Open the **Overview** tab and review or complete:

- Title and description  
- Modality  
- Categories  
- Other basics shown on the form (e.g. schedule / venue for face-to-face courses, if available)

Click **Save** when you change details.

---

## Step 3 — Add Modules (Lessons)

1. Open the **Modules** tab.
2. Click **Add Module**.
3. Enter:
   - **Module title**
   - **Description** (optional)
   - **Content type** — choose what learners will open:
     - **PDF Document** or **Slides**
     - **Video** (YouTube link or video file)
     - **Audio**
     - **Meeting Link**
   - **Content** — upload a file or paste a URL / YouTube link
   - **Weight (%)** — how much this module counts toward course progress (total of all modules should not exceed **100%**)
4. Save the module.
5. Repeat for each lesson.
6. **Drag modules** to set the correct learning order (Module 1, 2, 3…).

### Tips for modules
- Video modules can include **video checkpoints** (short questions during the video).
- PDF and slides are shown **page by page** to learners.
- After learners enroll, adding / deleting / reordering modules may be **locked**. Finish structure before publishing when possible.

---

## Step 4 — Add Assessments to Each Module

On the **Modules** list, each module shows badges:

| Badge | Purpose |
|--------|---------|
| **+ Pre-assessment** | Optional or required quiz before / at the start of the lesson |
| **+ Post-assessment** | Quiz after the lesson (usually required to finish the module) |
| **+ Video Checkpoint** | Questions during a **video** module (max usually 3) |

### How to add
1. Click **+ Pre-assessment**, **+ Post-assessment**, or **+ Video Checkpoint**.
2. Create the assessment and add questions (multiple choice, essay, etc.).
3. Save.
4. Return to the course workspace (**Modules** tab) to continue.

### Recommended learning design
For a typical video module:
1. Add the **video** module  
2. Add **video checkpoints** (optional but useful)  
3. Add a **post-assessment** (required for completion in most designs)  
4. Optionally add a **pre-assessment**

Learners unlock the post-assessment **after the video finishes**, then must pass it before marking the module complete.

---

## Step 5 — Access Tab (Optional)

Open **Access** to set enrollment and catalog options, such as:

- How learners enroll (e.g. approval required)  
- Visibility / who can see the course in the catalog  
- Expiry days (if used by your policy)

Save your changes.

---

## Step 6 — Instructors Tab

1. Open **Instructors**.
2. Assign the teachers who will manage this course and approve enrollments.
3. Save.

---

## Step 7 — Certificates Tab (Optional)

1. Open **Certificates**.
2. Set the **certificate prefix** (used in certificate codes).
3. Add **signatories** and e-signatures if required.
4. Save.

When a learner finishes all modules and passes required post-assessments, the system can issue the certificate automatically.

---

## Step 8 — Batches Tab (Optional)

Use **Batches** when the course runs by cohort / group (e.g. Batch 1 – March).

1. Open **Batches**.
2. Add batch names and details as needed.
3. Save.

Learners may select a batch when enrolling.

---

## Step 9 — Save and Publish

1. Click **Save** on the course workspace so all settings are stored.
2. Go to **Manage Courses** (course list).
3. Find your course and click **Publish**.

Until published, the course stays as a **draft** and is not available for normal learner enrollment in the catalog.

You can **Unpublish** later if you need to pause the course.

---

## Checklist Before Publishing

- [ ] Title, description, modality, and categories are correct  
- [ ] At least one module is added, in the right order  
- [ ] Module content (file / video link) opens correctly  
- [ ] Module weights total **100%** or less (as required by your process)  
- [ ] Post-assessments are linked to modules that need them  
- [ ] Video checkpoints added (if using video lessons)  
- [ ] Instructors assigned  
- [ ] Certificate settings completed (if certificates are required)  
- [ ] Batches set (if using cohorts)  
- [ ] Course is **Published**  

---

## After Publishing — What Happens Next

1. Learners find the course in **Course Catalog**.  
2. They request enrollment.  
3. You (or ETD) **approve** requests under **Enrollment Requests**.  
4. Learners complete modules → assessments → mark complete.  
5. When the course is finished, they receive a **certificate**.  

---

## Common Issues

| Problem | What to do |
|---------|------------|
| Cannot add or reorder modules | Learners may already be enrolled — structure is locked. Edit content of existing modules instead, or contact Admin/ETD. |
| Module weights error | Reduce weights so the total does not exceed 100%. |
| No Publish button / course not visible | Confirm you have Manage Courses permission and that the course was saved. |
| Learners cannot take post-assessment | For video modules, they must finish watching the video first. |
| Certificate not issued | Confirm all modules are completed and all required post-assessments are passed. |

---

## Quick Path (Short Version)

1. **Manage Courses** → **Create Course** → fill title, modality, categories → create draft  
2. **Modules** → Add Module (content + weight) → repeat → reorder  
3. Add **Pre / Post / Checkpoint** assessments per module  
4. Set **Instructors**, **Certificates**, **Batches** as needed  
5. **Save** → **Publish**
